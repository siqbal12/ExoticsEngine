Exotic Options Pricer w/ Web Infrastructure
- Pricing Engine: Developed an end-to-end Monte Carlo pricing engine for exotic derivatives (Arithmetic/Geometric Asians, Barriers, Digitals) under GBM, Heston, and Jump Diffusion dynamics
- Variance Reduction: Improved Monte Carlo standard error by 50%+ using Antithetic, Control, and Stratified Sampling
- Greek Calculations: Designed and implemented first-order Greek estimation framework (Delta, Theta, Vega, Rho) using Pathwise Differentiation and Resimulation methods

To run the application on your local browser:
- Run Backend
    - Run app.py
- Run Frontend
    - Go to Terminal
    - cd frontend
    - npm run dev
